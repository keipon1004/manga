## 1. 宿儺の器となった少年

人間の負の感情から生まれる呪いが人を害する世界。虎杖悠仁は友人と伏黒恵を救うため、特級呪物である両面宿儺の指を飲み込む。宿儺を体内に宿しながら自我を保つ特異な体質を持つ虎杖に対し、呪術界は処刑を決めるが、五条悟が猶予を取りつける。

虎杖は東京都立呪術高等専門学校に入り、伏黒、釘崎野薔薇と任務を経験する。人を救う願いは、全員を救えるわけではない現実に試される。真人が吉野順平の人生を壊す事件は、虎杖に、人間の魂を弄ぶ呪いとの埋めがたい断絶を突きつける。

## 2. 五条と夏油、0巻につながる過去

学生時代の五条と夏油傑は、天内理子の護衛を担当する。伏黒甚爾の襲撃によって理子は殺され、五条は力を覚醒させる一方、夏油は非術師を守り続けることに疑問を深める。二人は、同じ経験から異なる生き方へ分かれていく。

0巻では、祈本里香の呪いを抱えた乙骨憂太が高専に入り、仲間との関係を通して戦う意志を得る。乙骨を襲った夏油は敗北し、五条によって最期を迎える。後の本編に登場する「夏油」は、本人がそのまま生き延びた存在ではない。

## 3. 渋谷事変

京都校との交流や呪胎九相図との戦いを経た虎杖たちに対し、呪霊側は渋谷で大規模な罠を張る。五条は獄門疆に封印され、最強の抑止力を失った現場で術師と市民が犠牲になる。宿儺が虎杖の身体を支配した時間には、甚大な破壊が起こる。

七海建人は真人に殺され、釘崎も瀕死の重傷を負う。虎杖は罪悪感で折れかけるが、東堂葵に支えられ、真人を追い詰める。最後に真人を取り込んだのは、夏油の遺体を利用する羂索だった。羂索は次の計画へ進み、事件は一都市の惨事にとどまらず、日本全体の秩序を変える。

## 4. 死滅回游と伏黒の喪失

虎杖の処刑役に選ばれた乙骨は、実際には味方として動く。仲間たちは五条の解放と、殺し合いに巻き込まれた伏黒の姉・津美紀の救出を目指す。羂索の死滅回游は、術師同士の戦いを利用し、天元と人々を同化させるための準備だった。

各結界で戦い、得点とルールを利用して脱出の道を探る間にも、真希は真依の死を経て禪院家との決裂を迎える。虎杖と血縁的なつながりを持つ脹相は、敵から兄として寄り添う側へ移る。

津美紀には過去の術師・万が受肉しており、救出計画は崩れる。宿儺は虎杖との契約を利用して伏黒の身体を奪い、津美紀ごと万を殺害する。伏黒の生きる意志を折ることも、身体を支配する策略の一部だった。

## 5. 五条対宿儺と総力戦

五条は解放され、伏黒の身体に宿る宿儺と決戦する。領域、反転術式、魔虚羅の適応が絡む攻防の末、五条は敗れ死亡する。以後は一人の最強に任せる戦いではなく、乙骨、真希、日車、虎杖らが準備した手を重ねる総力戦となる。

並行して高羽の術式を利用した作戦から乙骨が羂索を倒す。宿儺は受肉した本来の姿で戦い続け、脹相は虎杖を守って命を落とす。虎杖は自身の能力を開き、単に肉体を倒すのではなく、伏黒と宿儺の魂の境を攻撃する道を探る。

## 6. 宿儺との決着と次の世代

虎杖の領域展開、戻ってきた釘崎が残された宿儺の指へ放つ術、伏黒自身の抵抗がつながり、宿儺は伏黒から引き離される。虎杖は最後まで共に生きる可能性を示すが、宿儺は受け入れず消えていく。羂索の目指した大規模同化も、この本編では実現しない。

生き残った術師たちは戦いを振り返り、虎杖・伏黒・釘崎は再び任務へ向かう。五条が託したのは、自分を再現することではなく、次の世代が別の道を選ぶことだった。呪いや術師の仕事がすべて消えたわけではなく、失った人々を抱えながら日常が続く形で終わる。
