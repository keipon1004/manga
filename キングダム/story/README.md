## 1. 信と嬴政、二つの統一への道

春秋戦国時代の秦。戦争孤児の信は、親友の漂と天下の大将軍になることを夢見ていた。王宮へ召された漂が致命傷を負って戻り、信は遺された指示をたどって秦王・嬴政に出会う。漂は政の身代わりにされたのだった。

信は怒りを抱えながらも、王弟・成蟜の反乱で追われる政に協力する。河了貂、山の王・楊端和らとの連携で王都を取り戻し、政は中華統一、信は大将軍という目標へ進む。二人の関係は主従だけではなく、互いの夢を実現するための約束に支えられる。

## 2. 歩兵から飛信隊へ、王騎の死

信は一兵卒として戦場に入り、味方を生かして勝つための判断を学ぶ。暗殺一族の出身である羌瘣も仲間となり、飛信隊が形成される。王騎は信に、目の前の敵を倒すだけではない将軍の視野を示す。

馬陽の戦いで秦軍は趙と激突するが、李牧の策によって戦局は覆る。龐煖との戦いで致命傷を負った王騎は、信へ矛と志を託して死ぬ。信にとって将軍は遠い憧れから、背負うべき死者と兵の重さを持つ目標へ変わる。

山陽では魏の廉頗軍と戦い、輪虎が信の前に立ちはだかる。王賁、蒙恬という同世代の将も競争相手となる。河了貂は軍師として飛信隊を支え、戦術面を補っていく。

## 3. 合従軍、蕞の防衛と政の政争

複数国が秦を攻める合従軍戦では、函谷関が国家存亡の防衛線となる。麃公らが命を落とし、別働隊を率いる李牧が王都へ迫る。政は蕞で民を励まし、自ら防衛戦の中心に立つ。住民と信たちは限界まで耐え、楊端和の援軍によって秦は危機を脱する。

戦場の勝利だけでは政の権力は安定しない。成蟜は新たな反乱の構図に巻き込まれて死に、毐国の反乱では後宮・宮廷の対立が表面化する。政は呂不韋との政治的対決を制し、昌平君も政の側へ移る。中華統一を国の方針として進める基盤が固まる。

## 4. 黒羊と鄴、将軍への昇格

黒羊丘では桓騎の残酷な手法が戦局を動かす。信は勝利のためなら何をしてもよいという姿勢と衝突し、敵国の民をどう扱うかが、統一の理想と実際の戦争の矛盾として現れる。

趙の要地・鄴を目指す遠征では、王翦の戦略と李牧の対応がせめぎ合い、秦軍は食糧不足を抱えて戦う。朱海平原では信・王賁・蒙恬が各軍を支え、信は龐煖との対決を制する。信自身も命の危機に陥り、羌瘣の働きで戻るが、これは彼女にとっても大きな代償を伴う出来事となる。

鄴の攻略は城を落とすだけでは終わらず、斉からの補給によって秦軍の占領が成立する。信は李信の名で将軍へ昇格し、漂と誓った夢に近づく。しかし統一の道は、個人の出世よりはるかに長い。

## 5. 桓騎の敗北と番吾の大敗

秦は魏との共闘による什虎戦を経て、再び趙へ攻勢をかける。影丘・扈輒戦では桓騎が勝つが、多数の捕虜殺害は信と政に重い問題を突きつける。軍の成果と人間の扱いは、同じ尺度では割り切れない。

宜安では李牧の準備した戦場に秦軍が引き込まれ、桓騎は逆転を狙いながら敗死する。さらに番吾では司馬尚率いる青歌軍が王翦軍を打ち破る。将を失い、兵力を消耗した秦は、それまでの侵攻の勢いを維持できなくなる。

## 6. 韓攻略から再度の趙戦へ

秦は戸籍整備と兵力再編などの改革を進め、騰と信を軸に韓攻略へ向かう。南陽の無血開城と占領地の統治は、領土だけでなく人々を秦へ組み込む難しさを示す。洛亜完らとの戦いを経て、韓王は降伏する。

78巻以降は韓の統治と、紀元前229年の趙攻略へ移る。79〜80巻では青華雲の弓が秦軍を脅かすが、その脅威を退けた後も李牧の策は続く。王賁が王翦への挟撃を阻み、信・蒙恬・羌瘣の連携した攻勢が新たな局面をつくる。

**80巻より先の勝敗や趙の滅亡、中華統一の完成は記述しない。** 歴史上の秦の結末を、そのまま漫画で既に描かれた出来事として補完しない。
