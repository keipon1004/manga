## 1. ボクシングとの出会い

母と釣り船屋を営む幕之内一歩は、学校でいじめを受け、自分に自信を持てずにいた。プロボクサー・鷹村守に助けられ、鴨川ジムでサンドバッグを打ったことから、仕事で培った身体の強さが見いだされる。一歩は鴨川源二の指導を受け、競技としてのボクシングを学び始める。

同年代の宮田一郎とのスパーリングは、一歩に明確な目標を与える。力と接近戦を武器とする一歩と、カウンターを磨く宮田は、対照的な技術を持つ好敵手となる。宮田との公式戦での再会を望みながら、一歩はプロの世界へ進む。

## 2. 新人王から日本王座への挑戦

一歩は速さ、リーチ、技術の異なる相手と戦い、そのたびに自分の弱点を補っていく。新人王戦では間柴了や千堂武士が大きな壁となり、勝利を重ねるなかで、相手にも負けられない人生があることを知る。千堂とは打ち合いを通じ、互いを認める関係が築かれる。

日本王者・伊達英二への挑戦では、経験の差に阻まれて初黒星を喫する。勝ち続けてきた一歩は敗北後の立て直しを迫られ、身体の回転を連続攻撃へつなぐデンプシー・ロールを身につける。伊達が世界へ進んだ後、日本王者となった千堂に再挑戦し、激闘を制して日本フェザー級王座を獲得する。

## 3. 防衛戦と鴨川ジムの仲間

王者となっても、一歩の課題はなくならない。真田、沢村、唐沢らとの防衛戦を経て、必殺技に頼るだけでは勝ち続けられない現実に向き合う。デンプシー・ロールは強力な一方、対策されうる技でもあり、基礎技術と身体づくりの重要性が増していく。

同じジムでは、鷹村が世界王座と複数階級制覇を目指し、青木・木村・板垣もそれぞれの限界や目標に挑む。一歩だけが成長する物語ではなく、ジムに集う選手と指導者たちの時間も並行して積み重なる。間柴の妹・久美との関係には、選手を心配する家族の視点が加わる。

## 4. 世界への距離と引退

一歩は国外の強豪との試合を通じ、日本王者と世界の頂点の間にある隔たりを意識する。アルフレド・ゴンザレス戦で敗れ、その後のアントニオ・ゲバラ戦にも敗北。蓄積したダメージへの不安と母への思いから、選手生活に区切りをつける。

ここで扱うのは、本人が身体への不安を抱いて引退を選んだという物語上の経緯である。病名や将来の復帰を断定するものではない。鴨川に教わったボクシングを伝えるため、一歩はトレーナー・セコンドの側から競技に関わるようになる。

## 5. リングの外から見えるもの

指導や練習相手を務める一歩は、現役時代とは異なる視点で技術や戦略を学び直す。ヴォルグや千堂らとの交流は続き、ライバルが世界へ進む一方で、一歩自身にも競技への思いが残る。セコンドへの転身は物語の終わりではなく、強さを考える別の段階となる。

メキシコではウォーリーが絶対王者リカルド・マルチネスに挑む。一歩は世界戦の攻防を見届け、自分と戦ってきた選手たちの到達点を目にする。間柴の世界戦準備にも協力し、選手を支える役割を深めていく。
