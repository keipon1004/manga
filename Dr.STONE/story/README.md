## 収録範囲

本編1〜26巻・第232話の結末まで。27巻の後日談は公開紹介で確認できるタイムマシン研究の継続までを補記。別作品の外伝は含めない。

## 1. 石の世界から文明を取り戻す

謎の光によって人類が石化し、文明が崩壊して数千年。科学好きの石神千空は目覚め、自然に覆われた世界で、既存の科学知識を使って生活基盤と復活液を作り出す。友人の大木大樹、小川杠とともに、石化した人々を救い出そうとする。

危険な自然から身を守るため復活させた獅子王司は、旧社会の権力や格差まで復活させることに反対し、若者を中心とする世界を築こうとする。誰も選別せず救う千空とは相いれず、文明の再建は、何を取り戻すのかをめぐる対立にもなる。

## 2. 石神村と科学王国

千空はコハクとの出会いから石神村にたどり着き、クロム、カセキ、スイカたちを仲間にする。村の人々が持つ観察力、技術、行動力を科学につなぎ、鉄、電気、薬、通信機を順に実現していく。ルリを治療する薬づくりは、科学が人の命を救うことを村に示す転機になる。

村の起源は、石化当時に宇宙にいた千空の養父・百夜らの生存者にある。長い歳月を越えて残された物語や資源は、千空の再出発を支える。千空一人の知識だけでなく、名前も知らない先人がつないだ仕事が文明復活の土台になる。

## 3. 司帝国との決着と海への進出

あさぎりゲンの交渉、通信、仲間同士の連携によって、科学王国は司帝国との戦いを進める。司の妹を救う可能性は和解の糸口となるが、氷月の行動によって司は重傷を負う。千空は司を救う将来の技術を信じ、彼を一時的に冷凍して生存の可能性をつなぐ。

航海のため七海龍水を復活させ、大型船を建造。科学王国は復活液の量産と石化の謎の解明を目指し、宝島へ向かう。海の向こうから届く不気味な通信は、ホワイマンという未知の相手の存在を示す。

## 4. 宝島とメデューサ

宝島では石化装置メデューサを利用して支配するイバラと対立し、多くの仲間が石化される。残った者たちは装置の条件を探り、技術と駆け引きで戦況を覆す。石化は恐怖であると同時に、解除に伴って損傷を修復する性質を持ち、司を救う手段にもつながる。

ホワイマンへの対処には月へ行く必要があると判明する。目標は、暮らしを維持する科学から、世界の協力で宇宙へ届く科学へ拡大していく。

## 5. 米国の科学者と南米での再石化

米国で出会うDr.ゼノは千空と同じく科学文明を再建していたが、スタンリーら軍事力を伴う集団を率いている。科学者同士の理解があっても支配の考え方は違い、両陣営は衝突する。千空たちはゼノを伴って南米へ向かい、石化の発生地を追う。

スタンリーとの戦いで仲間が次々に倒れ、全世界を再び石化させる決断へ追い込まれる。のちに目覚めたスイカは一人で復活液の再現に取り組み、長い孤独な作業の末に千空を復活させる。科学を知らなかった少女が学び、積み上げた成果が全員の未来を取り戻す。

## 6. 月面での対話と本編の結末

千空とゼノは協力へ進み、世界各地に資源・生産の拠点を築く。SAIの計算機開発など、多様な専門家の力を集め、月面到達を実現する。ホワイマンの正体は、人間の黒幕ではなく、宇宙から来たメデューサという機械生命体の集団だった。

石化による長期保存を利益とみなし、知的生命に自分たちを維持・増殖させようとする相手と、人類には根本的な認識の違いがあった。千空は単純な殲滅ではなく対話を選ぶ。地球では復活と復興が進み、大樹と杠が結婚する。一方、千空は石化技術を足がかりにタイムマシンという新たな不可能へ挑む。
