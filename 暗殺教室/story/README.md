## 1. 殺す相手が担任になる

椚ヶ丘中学校3年E組は、成績などを理由に本校舎から切り離され、差別的な教育制度の底辺に置かれていた。そこへ、月を大きく破壊し、翌年には地球も破壊すると告げる謎の生物が担任として現れる。生徒たちは政府から暗殺を依頼され、学校生活と暗殺訓練を同時に始める。

「殺せんせー」と呼ばれるその教師は、圧倒的な速さで攻撃をかわす一方、授業にも進路指導にも熱心である。潮田渚、赤羽業、茅野カエデらは、殺すべき相手から、自分の能力を見つけてもらうという矛盾した一年を過ごす。

## 2. 暗殺を通して自信を取り戻す

烏間惟臣が訓練を担当し、暗殺者イリーナも教師として加わる。生徒は射撃や体術だけでなく、観察、準備、協力の仕方を学ぶ。渚には殺意を読ませず接近する才能があり、業には高い能力と、失敗を受け入れにくい危うさがある。

学業面でもE組は変化する。学園の理事長・浅野學峯が作った序列へ対抗し、定期試験や行事で成果を上げる。暗殺の成功だけが成長ではなく、自分たちが一方的に劣った存在だという思い込みを崩すことが大きな軸となる。

旅行や島での訓練など、教室の外でも危機が起きる。鷹岡の暴力的な指導や外部の殺し屋と対峙する経験は、命令に従うだけではなく、自分で状況を判断する力を試す。

## 3. 教師と生徒、それぞれの隠された事情

生徒たちの家庭や将来にも問題がある。渚は母の期待と支配から距離を取り、自分の適性をどう生かすかを考える。誰かに評価されるためだけでなく、自分の意志で進路を選ぶことが、殺せんせーの教育と結びつく。

茅野は、実は前担任・雪村あぐりの妹だった。姉の死に殺せんせーが関わったと考え、復讐のために素性を隠していた。身体に仕込んだ触手を使って襲うが、渚たちの働きによって救われる。明るい同級生という顔の奥にあった憎しみが、過去を聞くきっかけになる。

## 4. 殺せんせーの過去

殺せんせーは元は人間で、初代「死神」と呼ばれる暗殺者だった。弟子の裏切りで捕らえられ、柳沢の実験によって異形の身体へ変えられる。そこで出会ったあぐりは、彼を実験体としてではなく、一人の存在として扱った。

月の破壊を起こしたのは、実験に用いられたマウスだった。地球を壊す可能性は殺せんせー自身の身体にも関わるが、月を自分で直接破壊したという当初の理解は修正される。あぐりの死に際の願いを受け、彼は彼女が担任していたE組を教えることを選んだ。

過去を知った生徒たちは、当初の任務をそのまま続けるだけではいられなくなる。恩師を殺すのか、救う方法を探すのかで教室は割れる。

## 5. 救命の調査と政府の決定

業と渚を中心にした対立は、実戦形式の勝負で決着をつける。生徒たちはまず救う可能性を調べることにし、宇宙での研究データにもアクセスする。地球破壊の確率は極めて低いと分かるが、政府は不確実性を受け入れず、殺せんせーを確実に排除する計画を進める。

大人の安全保障上の判断と、生徒が一年かけて築いた関係は一致しない。E組は封鎖された校舎へ戻ろうとし、自分たちの担任と最後まで向き合う道を選ぶ。

柳沢と二代目死神も襲来し、茅野は致命傷を負う。殺せんせーは激戦のなかで彼女を救い、最後の力を使う。これは暗殺の授業の延長であると同時に、教え子を守る教師としての行動でもある。

## 6. 最後の出席確認と七年後

弱った殺せんせーは生徒たちを受け入れ、最後の出席を取る。生徒が押さえるなか、渚が刃を入れ、殺せんせーは死ぬ。依頼されたから機械的に実行する暗殺ではなく、一年を共有した彼ら自身が引き受ける別れとなる。

卒業を迎えた生徒には、殺せんせーが準備した助言が残される。E組制度は終わり、旧校舎は生徒たちにとって戻れる場所として保たれる。賞金も単純な個人の富としてだけは扱われない。

七年後には、それぞれの道を歩く元生徒たちが描かれる。渚は教育実習生として荒れた教室に立ち、殺せんせーから受け取ったものを次の生徒へ伝えようとする。渚と茅野の結婚を示す結末ではなく、全員の将来が一つの形にそろうわけでもない。
