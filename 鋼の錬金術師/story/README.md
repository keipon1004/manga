## 1. 人体錬成の代償

エドワードとアルフォンスのエルリック兄弟は、亡くなった母を取り戻そうと禁忌の人体錬成を行う。試みは失敗し、エドは左脚、アルは全身を失う。エドは右腕を代価に弟の魂を鎧へ定着させるが、母は戻らない。

幼なじみのウィンリィとピナコの支援で機械鎧を得たエドは、国家錬金術師となる。マスタングのもとで軍に関わりながら、兄弟は元の身体へ戻る方法を探して旅立つ。万能の力に見える錬金術にも、取り返せないものがあるという出発点は最後まで残る。

## 2. 賢者の石と人間の命

リオールでの宗教的欺瞞、ショウ・タッカーが娘ニーナを犠牲にした実験を通し、兄弟は力を持つ者が他者を道具にする恐ろしさを見る。国家錬金術師を狙うスカーとの遭遇は、軍が起こしたイシュヴァール殲滅戦の責任にもつながる。

身体を取り戻す鍵として求めた賢者の石は、人間の命から作られていた。第五研究所やマルコーの情報は、事件が一人の研究者の暴走ではなく、軍の深部につながっていることを示す。兄弟は石の便利さだけを頼って進む道を拒み、別の方法を探す。

調査を進めたヒューズは国の構造に秘密があると気づくが、エンヴィーに殺害される。家族と仲間を失ったマスタングたちにとっても、真相究明は個人的な復讐と国家の改革が重なる課題となる。

## 3. ホムンクルスとイシュヴァールの傷

ラスト、グラトニー、エンヴィーらホムンクルスは、人間を超えた再生力を持ち、国の裏側で計画を進めている。大総統ブラッドレイもその一員であり、軍を通じて動けば安全だという前提は崩れる。

シンから来たリン・ヤオとメイ・チャンは、不老不死や錬丹術を求めて兄弟の旅に加わる。リンはグリードを身に宿し、支配されるだけではない共存関係を築いていく。異なる国の技術と視点が、アメストリスの錬金術の仕組みを見直す糸口になる。

スカーはウィンリィの両親を殺した人物でもある。ウィンリィは怒りを抱えながらも、その場で命を奪うことを選ばない。スカー自身も復讐だけでは世界を変えられないと知り、兄の研究を受け継ぐ道へ進む。

## 4. 国土そのものが錬成陣

北方ブリッグズでオリヴィエ・ミラ・アームストロングらと出会った兄弟は、各地の戦争と流血が巨大な錬成陣を形作ってきたと知る。国を挙げた戦争は、国民全体を材料にする計画の一部だった。

黒幕「お父様」は、エドとアルの父ホーエンハイムと外見が似ている。古代クセルクセスで生まれたその存在は、多数の命を奪って人の形と力を得た。ホーエンハイムも不死に近い身体となったが、内側にいる一人ひとりの魂と向き合い、長い年月をかけて対抗策を準備していた。

父を家庭から逃げた男だと思っていたエドも、その過去を知る。兄弟、軍の反乱勢力、スカーらは立場を越えて協力し、約束の日に備える。

## 5. 約束の日と「お父様」の敗北

中央では軍部との戦いが起こり、ホムンクルスとの因縁も決着へ向かう。マスタングはエンヴィーへの憎悪で自分を見失いかけるが、ホークアイらに止められる。彼もまた、復讐だけを目的に進まない選択を求められる。

「お父様」は国民の魂を使って巨大な力を取り込むが、ホーエンハイムの対抗策で人々は戻され、スカーの錬成陣も作用する。仲間の攻撃によって追い詰められた「お父様」に対し、アルは自分の魂を代価にエドの右腕を戻す。エドは生身の腕で戦い、グリードの抵抗も経て敵は敗北する。

## 6. 何を差し出し、何を残すか

弟を連れ戻すため、エドは自分自身の「真理の扉」を差し出す。錬金術を使う能力を失う代わりに、アルの身体と魂を取り戻す。兄弟は他人の命ではなく、自分の力を手放すことで旅の目的に届く。エドの左脚は機械鎧のままであり、すべてが事故前へ戻ったわけではない。

ホーエンハイムはトリシャの墓の前で生涯を終える。国の再建とイシュヴァールへの償いはこれからも続き、兄弟はそれぞれの方向へ学びの旅に出る。エドとウィンリィは将来を約束し、巻末では子どもたちを含む家族の姿が示される。

物語は錬金術そのものを万能の救済にせず、人の手や関係によって生き直す結末を選ぶ。軍の罪や亡くなった人々が帳消しになった、という終わりではない。
