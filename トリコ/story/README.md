## 1. 美食屋と料理人の旅

未知の食材が世界を動かす時代、美食屋トリコは、自分の人生を代表するフルコースを探して危険な土地へ赴く。料理人の小松は、最初こそ圧倒的な生物や戦いに戸惑うが、食材の持ち味を引き出す腕と誠実さで、トリコに不可欠な相棒となる。

食べるための力を持つトリコと、食べ物を料理へ変える小松の役割は違う。旅は強敵を倒す競争だけではなく、食材を見つけ、調理し、誰かと分かち合うまでをつないでいく。二人が探すものも、名声や希少性だけで選ぶ献立ではなく、出会いと思い出を含む一食へ育っていく。

## 2. 人間界の冒険と四天王

ガララワニ、虹の実、フグ鯨などの食材をめぐる冒険から、IGOの管理する世界と、その外に広がる危険が見えてくる。トリコと同じ四天王のココ、サニー、ゼブラは、それぞれ毒、髪、音に関わる独自の能力を持つ。性格の違う彼らが、小松を含む仲間との協力を学ぶ。

美食會は強い食欲と武力によって食材や料理人を奪い、トリコたちと衝突する。スタージュンは特に大きな存在で、単なる障害ではなく、戦いを通じて互いの力を認める相手となる。伝説の美食神アカシアの食材、とりわけGODが、複数勢力の行動を結ぶ中心になる。

## 3. センチュリースープから料理人の争奪へ

極寒のアイスヘルでは、伝説のスープを求めて多くの者が危険を冒す。トリコが食材を守る側で戦う一方、小松は失われた味の再現へ挑戦する。トリコの腕の負傷と再生も含め、二人それぞれの努力が、次の旅へ進む条件となる。

メロウコーラなどの探索では、ゼブラとの行動を通して世界が広がる。食義を学ぶ段階では、食への感謝が単なる礼儀ではなく、身体と食材の扱いを変える技術として描かれる。食運という不思議な力も、小松の料理人としての資質に関わっていく。

料理人の祭典クッキングフェスは、美食會の襲撃で戦場となる。一龍と三虎の対立、その背後で動くNEOの存在が明らかになり、人間界の秩序は大きく崩れる。小松も敵の側へ連れ去られ、トリコにとって食材探索と相棒の救出が重なる。

## 4. グルメ界とアカシアのフルコース

人間界よりはるかに厳しいグルメ界では、八王と呼ばれる存在が各地の生態系を支配する。トリコたちは力任せでは越えられない条件に向き合い、AIR、PAIRなど、アカシアのフルコースを構成する食材を求める。

馬王の領域では食材の成長条件が、猿王バンビーナの領域では身体の使い方が試される。小松の命が危機に陥ったことで、食材の獲得は仲間を救うための切実な行動にもなる。ブルーグリルやANOTHERをめぐる局面では、料理に必要な時間と技術の規模も常識を越えていく。

これらの食材は個別の宝探しの目的物であると同時に、地球とグルメ細胞の歴史、アカシアが進めてきた計画を理解する鍵となる。人間界の冒険で築いた人脈と調理技術が、世界規模の危機で力を発揮する。

## 5. GODとNEOをめぐる最終決戦

GODの出現に向け、アカシア、三虎、四天王らが集まる。次郎やドンスライムを含む強者たちにも犠牲が出て、最強の食欲を持つNEOの脅威が表面化する。トリコとスタージュンがアカシアとフローゼの子であることも明らかになり、敵味方の関係が家族の歴史と重なる。

トリコは自分の内側のグルメ細胞の悪魔とも向き合い、アカシアとの決戦に臨む。最終的にNEOの際限ない食欲をめぐる戦いは決着し、世界には再び食事を分かち合う時間が戻る。失われた人々の物語も、食卓を囲む家族のイメージへつながっていく。

## 6. 結婚式と、その先の食材

トリコはリンと結婚し、披露宴では、それまでの冒険で出会った食材がフルコースとして並ぶ。豪華な献立は、二人だけの成功の証ではなく、食材を守り、運び、料理した多くの人々との関係を振り返るものとなる。

最終話では、地上の冒険で終わらず、トリコと小松は宇宙へ新たな食材を探しに出る。二人の相棒関係は続き、完成したフルコースも、世界への好奇心を閉じる終着点にはならない。宇宙での全冒険を描き切ったわけではなく、新しい旅の始まりを示して完結する。
