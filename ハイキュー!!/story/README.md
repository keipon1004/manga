## 収録範囲

完結。本編全45巻・第402話まで。高校一年の大会から卒業後・プロ・代表・海外クラブの最終場面を含む。

## 1. 敵だった二人が同じコートへ

小柄な日向翔陽は、テレビで見た烏野高校の「小さな巨人」に憧れてバレーボールを始める。中学最後の大会で影山飛雄に敗れ、いつか倒すと誓うが、高校で同じ烏野の部員になる。高く跳ぶ日向と、精密なトスを上げる影山は、最初はぶつかり合いながらも速攻の組み合わせを見つける。

かつて強豪だった烏野は低迷していた。澤村、菅原、東峰ら上級生、西谷、田中、同級生の月島・山口、マネージャーの清水・谷地、武田顧問と烏養コーチが、異なる役割でチームを支える。日向の跳躍だけでも、影山の技術だけでも試合は成立しない。

## 2. インターハイ予選での敗北

練習試合や大会を経て、日向は相手を引きつける「囮」としての価値を知る。一方、影山は中学時代に味方を置き去りにした独善的なトスを改め、打ち手と噛み合わせることを学ぶ。東峰と西谷の復帰によって攻守の形も整っていく。

インターハイ予選では伊達工業の高いブロックを越えるが、及川徹率いる青葉城西に敗れる。及川は派手な個人技だけでなく、各選手の力を引き出して戦うセッターであり、烏野の速攻だけでは届かない差を示す。

敗北後も三年生が残り、春高を目指す。日向は目を閉じて影山に任せる速攻から、自分も空中で判断する攻撃へ進もうとする。その要求は二人の衝突を生むが、関係を壊すのではなく、新しい連携を作る課題となる。

## 3. 東京合宿と春高代表決定戦

東京の合宿では音駒、梟谷などと練習を重ねる。日向は木兎や赤葦らから学び、月島も黒尾らとの交流でブロックへの姿勢を変えていく。山口はピンチサーバーとして役割を磨く。各自が別の場所で得たものが、烏野の攻撃を一つの速攻だけに頼らない形へ変える。

春高予選で烏野は青葉城西と再戦し、前の敗北を越えて勝利する。決勝の相手は牛島若利を擁する白鳥沢。強烈な個の力に対し、烏野はブロック、レシーブ、交代選手を含む総力で対抗する。月島が牛島の攻撃を止めた場面は、彼が競技へ熱を持つ転機になる。

五セットの戦いを制し、烏野は全国出場を決める。勝った側の歓喜の隣には、敗れた相手の高校生活もあり、敵校の選手も次の道へ向かっていく。

## 4. ボール拾いから全国へ

影山が全日本ユースの合宿へ呼ばれる一方、日向は選ばれていない県内の合宿へ押しかけ、球拾いとして残る。そこでコートの外から観察し、相手の動きやレシーブの基本に目を向ける。高く跳べることだけでは、長くコートに立てないと気づく経験となる。

全国では椿原学園に勝ち、宮侑・宮治らの稲荷崎と激突する。相手も速攻を再現し、サーブで圧力をかけるが、烏野は粘り強い守備と連携で応戦する。日向の成長は、得点を取る場面だけでなく、ボールを丁寧につなぐ動きにも表れる。

続く音駒との「ゴミ捨て場の決戦」では、孤爪研磨の戦略と烏野の攻撃が向き合う。負ければ終わる公式戦を長く望んでいた両校は、全力のラリーを交わし、烏野が勝つ。研磨にとっても試合の面白さが実感になる。

## 5. 鴎台戦と高校の先

星海光来を擁する鴎台は、完成度の高いブロックと守備で烏野を追い込む。日向は手応えを得るが、発熱で離脱する。身体の管理も実力の一部だという現実が、最も大切な試合で突きつけられる。烏野は敗れ、三年生と戦う大会は終わる。

物語は残りの高校生活すべてを同じ密度で追わず、卒業後へ進む。日向はブラジルでビーチバレーに取り組み、二人でコート全体を守る環境から、サーブ、レシーブ、トス、状況判断を学び直す。影山と再び競うためにも、自分一人でできることを増やしていく。

## 6. プロでの再戦と最終話

帰国した日向はMSBYブラックジャッカルに加わり、シュヴァイデンアドラーズの影山と対戦する。木兎、宮侑、佐久早、牛島、星海ら、かつてのライバルも両陣営へ分かれる。日向は速攻だけに特化した選手ではなくなり、影山もその成長へ全力で応じる。試合はブラックジャッカルが勝つ。

最終話では元選手たちの多様な進路が描かれ、競技を続ける者だけが成功者とはされない。日向と影山は日本代表で再び組み、アルゼンチン代表となった及川と対峙する。ただし、この代表戦の最終スコアを本編は示さない。

最後は2022年、ブラジルとイタリアのクラブに分かれた日向と影山が世界クラブ選手権の決勝で向き合う。高校で完成して終わる関係ではなく、味方にも敵にもなりながら挑み続ける二人の姿で完結する。
