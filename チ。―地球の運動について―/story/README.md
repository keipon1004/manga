## 1. ラファウと危険な学説

15世紀のP王国。神童と呼ばれる少年ラファウは、合理的に生き、神学で立身する道を選ぼうとしていた。しかし異端として扱われるフベルトとの出会いによって、地球が動くという考えに触れる。天体の観測を、自分の目で世界を知る行為として経験し、予定していた生き方が揺らぐ。

当時の権威に逆らう学説は、単なる学問上の対立では済まない。審問官ノヴァクは地動説を追い、ラファウにも信念を捨てる選択を迫る。ラファウは生き延びるための合理性ではなく、自分が美しいと感じた世界の理解を選び、命を落とす。

最初の主人公の死によって、物語は一人の天才が最後まで成功する形を取らないことが明確になる。研究の痕跡は隠され、後の誰かがそれを見つける可能性へ託される。

## 2. オクジー、バデーニ、ヨレンタ

約十年後、代闘士オクジーは、危険な文書と天体観測に関わることになる。自分が暮らす地上を醜いものと考えていた彼にとって、地球も天と同じ宇宙の一部だという発想は、生きる場所の見え方を変えるものだった。

学僧バデーニは卓越した知性を持つが、名誉や自分の能力への強い執着も抱えている。学問への接し方がまったく違うオクジーとの協力は、研究を前へ進めるだけでなく、知識を誰のものにするかという問題を生む。

ヨレンタは天文学の研究をしているが、女性という立場によって成果を正当に扱われにくい。観測家ピャストの記録も関わり、先人の誠実な観測が、新しい理論を組み立てる材料となる。彼らが目指すのは、単に権威を否定することではなく、観測を説明できる体系を作ることだった。

## 3. 書くことと、名を残せない人々

オクジーは研究の当事者となり、文字を学んで自分の経験を記録し始める。論文だけが知識の器ではなく、世界の見方が変わった一人の言葉も、後に意味を持つ。

一方、審問の手は迫る。ノヴァクはヨレンタの父でもあり、家庭で娘を大切にする顔と、仕事として他者を追及する顔が同じ人物にある。彼にとっての秩序の維持は、研究する側の命と自由を奪うものになる。

オクジーとバデーニは捕らえられ、処刑される。しかし残された記録は、社会の周縁にいる人々の協力によって受け継がれる。バデーニの計画も、自分一人の名声を守る方向から、誰かが読める未来へ開かれていく。ヨレンタは生き延び、次の時代の伝達へ関わる。

## 4. ドゥラカと出版の可能性

さらに約二十五年が過ぎ、商売や利益の感覚を持つドゥラカが、引き継がれた記録に出会う。彼女の出発点は、ラファウやバデーニと同じではない。知識を広げる動機には信念だけでなく、事業や状況判断も関わる。

シュミットらの解放組織、そして成長したヨレンタは、印刷を使って学説を広めようとする。一冊の写本を隠す段階から、複数の人に届く形で公にする段階へ、伝え方そのものが変わる。名も顔も知らない人間に任せることが、思想を個人の死から切り離す方法になる。

追手の包囲と犠牲のなかで、ドゥラカたちは出版の可能性をつなごうとする。老いたノヴァクも追跡を続け、自分が葬ったはずのものが、人から人へ残っていたことに向き合う。

## 5. 最終部のアルベルト

終盤では舞台にポーランドという実名が現れ、若いアルベルトの学びが描かれる。ここにはラファウという名の大人も登場するが、初期の少年の再登場だと単純に断定できる描かれ方ではない。知への執着は常に善い結果だけを生むわけではなく、暴力や他者の犠牲と結びつく危険も示される。

父を失ったアルベルトは学問から離れるが、再び学ぶことへ向かう。物語は地動説が即座に社会へ承認され、全員の名誉が回復する式典で終わるのではない。過去の担い手が知りえない先へ、学びたいと思う心が残るところで閉じられる。

## 6. 事実と解釈の境界

各部で主人公が変わり、記録と感動が受け継がれることは物語の構造である。一方、最後のラファウを同一人物の蘇生とする説、別世界への移行とする説などは、ここでは確定設定として採用しない。

また、P王国とC教を用いた前半を、そのまま実在の教会による地動説弾圧の実録に置き換えない。作中の拷問・処刑と実際の科学史は別に検証すべきである。本要約も、歴史上の地動説成立の年表を代わりに提示するものではない。
