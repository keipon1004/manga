# manga

漫画・アニメの視聴・読書記録用リポジトリです。事実（ストーリー）と自分の解釈（感想）を分けて Markdown で残します。

## ディレクトリの考え方

各作品ごとにフォルダを1つ作り、次の構成にします。

```text
（作品名）/
├── README.md      … 進捗・メモ（ネタバレ方針、参照元など）
├── story/         … 出来事・伏線など「事実」のメモ
└── 感想/          … 自分の印象・解釈
```

- **story/** … 原作・配信で確認できた内容だけを書く。推測は書いてもよいが、根拠が弱いものは **未確認** と明記する（下記）。
- **感想/** … 好き嫌い、考察、比較など、主観はすべてこちら。

## ファイル名（アニメ・漫画）

| 種類 | story / 感想 の例 |
|------|-------------------|
| アニメ（話） | `第001話.md`（3桁ゼロ埋め推奨） |
| 漫画（巻） | `第001巻.md` |
| 漫画（話・掲載号単位） | `第001話.md` など、作品に合わせて統一 |

1作品の中では命名規則を揃え、`README.md` に「話単位／巻単位」を一行メモしておくとよいです。

## 新しい作品を追加する手順

1. ルートの `テンプレート/` をコピーし、フォルダ名を正式な**作品名**に変更する。
2. `（作品名）/README.md` のプレースホルダを埋める（進捗は空のままでも可）。
3. 見終わった話・巻ごとに、必要なテンプレートファイルを `story/` と `感想/` にコピーしてリネームし、中身を書く。
4. 使わないサンプル（例：巻用テンプレだけ使う場合の話用ファイル）は削除してよい。

**読了履歴や作品内容はここには書かない** — 自分が実際に追った分だけファイルを増やしてください。

## 未確認の書き方

根拠がはっきりしない情報（未放映話の推測、記憶違いの可能性など）は、次のどちらかで区別します。

- 本文中に `（未確認）` と付ける  
- または `story` 内の「未確認・メモ」見出しにまとめる

感想側の考察と混ぜないよう、未確認の事実仮説は **story** 側に置くことを推奨します。

## テンプレート

空のひな形はすべて **`テンプレート/`** にあります。実データ用の作品フォルダは自分で追加します（リポジトリにはサンプル作品名は含めていません）。

## このリポジトリでやらないこと

- 自動同期・アプリ・スクリプトによる一覧生成は想定していません。
- ファイルを追加・編集するだけのシンプルな運用です。
