## 収録範囲

## 1. 壁の中の人類とエレンの決意

巨大な壁に守られた街で暮らすエレン・イェーガーは、壁の外へ行くことを望んでいた。超大型巨人と鎧の巨人が防壁を破り、母が巨人に食われたことで、巨人を駆逐するという強い目的を抱く。ミカサ、アルミンとともに兵士となり、生き残った人類の戦いへ加わる。

トロスト区の戦いで、エレン自身が巨人になる力を持つと判明する。人類を襲うものと同じ力を使う彼をどう扱うかで軍は揺れ、リヴァイやエルヴィンのもとで調査兵団がその力を引き受ける。エレンの父が遺した地下室は、世界の真相に近づく目標となる。

## 2. 仲間の正体と王家の秘密

女型の巨人は同期のアニだった。続いてライナーとベルトルトが鎧と超大型の正体を明かし、巨人との戦争は、共に訓練した仲間との戦いになる。ユミルとヒストリアの関係からも、王家と壁の内側に隠された事情が見えてくる。

巨人の多くは人間が変化した存在であり、壁の中にも巨人が埋め込まれていた。人類を守るという壁の意味そのものが変わっていく。エレンが持つ始祖の力は父グリシャから受け継いだもので、レイス家はそれを取り戻そうとする。

ヒストリアは父ロッドの意図に従ってエレンを食うことを拒み、自分の意志で行動する。軍と王政をめぐる対立を経て女王となり、壁内の体制は変わる。しかし政治を変えても、外の敵と巨人の謎は残っている。

## 3. シガンシナ奪還と地下室

調査兵団は故郷シガンシナへ向かい、獣・鎧・超大型らと激突する。エルヴィンは兵とともに死地へ進み、アルミンも身を焼かれる。限られた巨人化薬を誰に使うかという選択でアルミンが救われ、ベルトルトを食べて超大型を継承する。勝利は多数の犠牲と切り離せない。

地下室の記録は、壁外に人類が存在することを示す。彼らは孤島パラディに暮らすエルディア人であり、大陸のマーレでは同胞が差別され、巨人の力を戦争へ利用されていた。壁外は自由だけが広がる場所ではなかった。

エレンたちは海に達するが、その向こうにも敵がいる。巨人を倒せば自由になるという当初の見通しは失われ、民族、国家、歴史の問題へ戦いが拡大する。

## 4. マーレへの攻撃と島の分裂

大陸ではライナーや、ガビ・ファルコら戦士候補生の側からも世界が描かれる。彼らも教育と差別のなかで生きており、敵の民にも守りたい日常があることが示される。エレンはマーレへ潜入し、レベリオを攻撃する。島の仲間は彼を回収するが、その独断は内部の対立を深める。

エレンの異母兄ジークは、始祖の力によってエルディア人が子を持てなくなる計画を進める。島ではイェーガー派が勢力を広げ、軍の指揮系統も崩れる。エレンは友人たちとも距離を置き、未来の記憶と自分の願いを抱えたままジークとの接触へ向かう。

## 5. 地鳴らしと、かつての敵との共闘

道で始祖ユミルの過去に触れたエレンは、ジークの計画には従わず、壁の巨人を解放する。地鳴らしによって島外の世界が踏み潰され、多数の無関係な人々が殺される。島を守るという理屈で正当化されても、仲間は虐殺を受け入れない。

アルミン、ミカサ、リヴァイらは、ライナー、アニら旧敵と組んでエレンを止めに行く。ハンジは仲間の出発を支えて死に、残された者たちは最終戦へ向かう。互いの加害を消せないまま協力することが、この連合の前提となる。

## 6. 原作の決着と長い時間

リヴァイがジークを殺すことで地鳴らしは止まり、最後にミカサがエレンの命を断つ。エレンへの愛情を持ちながら殺すという彼女の選択は、ユミルを縛ってきたものの解放につながる。巨人の力は消え、巨人化した人々も人間へ戻る。

エレンが死ぬまでに、人類のおよそ八割が失われた。仲間との記憶の対話は彼の複雑な動機を示すが、虐殺が必要で正しかったと認定するものではない。三年後、アルミンたちは交渉へ向かい、ミカサは故郷の木の下に埋葬したエレンを悼む。

34巻追加ページは、ミカサのその後と、はるかな時代の戦争による破壊、木へ近づく少年と犬を示す。**ミカサの配偶者の名、巨人の確実な復活、時間ループの成立は明示された事実ではない。** 巨人の消滅が戦争の永久的な終わりを保証しない余韻とともに完結する。
